LMS Redesign – Functional Flow Guide

How the training module works across the Admin app, the Web learner app and the Mobile learner app. Updated 15 Oct 2026.

OverviewKey rulesAdmin flowWeb learner flowMobile learner flowStatuses and labelsNotes

Overview

The training module is one content structure, Course → Section → Videos + one Section Quiz, delivered through three surfaces that share the same rules.

SurfaceWho uses itWhat it does
Admin appTraining adminsCreate courses, sections, videos and quizzes
Web learner appEmployees on desktopWatch courses, take section quizzes, track progress
Mobile learner appEmployees in a mobile appSame as web, opened from the app's side menu, themed to the host app

Content model:

  • Course: one per product, for example Schedules, Sales app, Plum POS. Has a name and an Active switch.
  • Section: an ordered group of videos inside a course, for example Getting started, Scheduling shifts, Report, Settings.
  • Video: a name, a URL, a sequence number (1 is first) and an Active switch. Belongs to one section.
  • Section Quiz: optional, one per section. Has questions, answer options, a pass mark and learner rules.

Difficulty levels and role tabs (Cashier, Manager, Server) were removed from the learner UI. Role filtering, if used, happens in the backend.

Key rules

These rules apply on web and mobile alike.

RuleBehaviour
Video progressSaved automatically as the learner watches. Rewind is allowed; skipping ahead is not. A video counts as watched at 100%.
Auto-advanceWhen a video finishes and the section has more videos, the next one loads and starts about 1 second later, with an "Up next" message.
Quiz unlockA Section Quiz unlocks only when every video in that section is watched. Until then it shows Locked with "x of y watched".
Pass markSet per quiz (for example 70%). Score = correct answers ÷ questions. Best score is kept.
Section statusNot Started → In Progress (any video watched) → Completed (all videos watched and, if there is a quiz, quiz passed). Coming Soon if it has no videos.
Course statusCompleted when every section with videos is completed; In Progress once anything is watched; otherwise Not Started.
Course progress %Average watched % across all videos in the course. Shown as <1% when above zero but rounds to 0.
Section focusOpening a course expands the first section that is not completed. When a section is completed, it collapses and the next unfinished section opens.
ResumeContinue buttons go to the first partly watched video, else the first unwatched one.
Correct answersAfter a pass, wrong answers show the correct one. After a fail, correct answers stay hidden so a retake still tests the learner.
Completed courses (mobile)Hidden from Other Courses; "Show Completed Courses (n)" brings them back for review.
OrderingVideos follow their sequence number within a section. Sections follow the order set in the admin Curriculum.

Admin flow

Admins build every course in one place: Course list → Course manager (Curriculum) → sections, videos and quizzes.

  1. Course list
    • Search and Status filter (All, Active, Inactive).
    • Table: #, Course, Sections and videos, Quizzes, Status, Actions.
    • 3-dot Actions menu: Edit this course, View course on frontend (learner preview), Delete course (asks first, lists what will be removed, suggests setting Inactive instead).
    • New course: enter a name, then the course manager opens.
  2. Course manager
    • Header: name, counts, status, View on frontend, Back to course list.
    • Tabs: Curriculum and Basic info (name and Active switch, saved automatically).
  3. Curriculum
    • Toolbar: Add section, Add videos, Add quiz, Sort sections (shows up/down arrows on sections).
    • Each section card: Section n: name, video and quiz counts, + Video, + Quiz, Rename, Delete (warns how many videos and quizzes go with it). Sections open and close.
    • Video rows: sequence box, up/down arrows, Active switch, Edit, Delete. Typing a sequence number moves the video and renumbers the rest (no gaps or duplicates).
    • Quiz rows: name, question count, pass mark, Required and Active badges, Edit quiz, Delete.
  4. Add / edit videos
    • Choose the section, then add rows one by one or Paste a list ("Name, URL" per line, or two Excel columns), review, and save.
    • Optional sequence per row; empty means add to the end. Missing names and invalid URLs are flagged per row.
  5. Quiz builder (3 steps)
    1. Details: section, quiz name, type, order in the section, description.
    2. Settings: pass mark; attempts (Unlimited or a limit); time limit (none or minutes); when it unlocks (Any time or After the section videos); switches for Active, Required, Shuffle questions, Shuffle answer options, Show correct answers after submitting, Allow skipping questions.
    3. Questions & answers: question list on the left, editor on the right. Answer type (one or more correct), points, Active, options with a correct-answer marker, optional image/video link, reorder, duplicate, delete.
    • Next is blocked until a step's required fields are valid. Save is blocked until every question is valid and opens the step and question that need fixing. Unsaved changes are protected when leaving.

Web learner flow

The web app takes a learner from My courses to a course page, then into videos and the Section Quiz.

  1. My courses (home)
    • Header panel: overall completion ring, a status bar split into completed, in progress and not started, and up to 3 "Pick up where you left off" chips ("+n more" if there are more).
    • "View all my courses" switches the filter to All and scrolls to the list.
    • Summary tiles: Enrolled courses, In progress, Completed, Quizzes passed.
    • Filters: All, In progress (default), Completed. Search by course name or description. Sort: Recommended, Title A–Z, Highest rated, Most progress.
    • In the All view, Recommended order lists in-progress courses first, then not started, then completed.
    • Every action on a course card (title, cover play button, Start, Continue, Watch again) opens the course page.
  2. Course page
    • Top bar: a Back button (top-right) returns to My courses.
    • Header: course name, section and video counts, overall progress and a Continue button that jumps to the next video.
    • Course content: one accordion card per section, colored by status (green = completed, blue = in progress, grey = not started).
    • The first unfinished section is open by default; completed sections collapse and the next opens. "Expand all / Collapse all" toggles every section.
    • Each open section lists its videos in sequence order with progress, then its Section Quiz.
  3. Video player
    • Top bar: course · section label and a Back to Course button (top-right).
    • Play fills the progress bar; course and section progress update as the learner watches.
    • Auto-advance to the next video in the section; Previous and Next buttons for manual moves.
    • Right column: the section's video list (current highlighted) and its Section Quiz panel.
  4. Section Quiz
    • Locked until all section videos are watched. Clicking a locked quiz ("Watch videos first") opens the first unwatched video.
    • One question at a time with numbered jump buttons and an answered count. Next is blocked until an answer is chosen; Submit sends the learner to any skipped question.
  5. Result
    • Score, correct count and pass mark, then each answer marked right or wrong.
    • Pass: Back to course (and optional retake). Fail: Retake quiz or Watch the video again.

Mobile learner flow

On mobile, the course for the app the learner is signed into comes first, and every other course sits under Other Courses.

  1. Entry
    • Side menu (☰) → My Account → Training Videos. The menu item shows an "n In Progress" count.
    • Colors come from the host app's theme. Schedules uses the blue theme; Sales app and Plum POS use their own.
  2. Home – Courses tab
    • Continue Watching card: jumps straight to the next video, preferring the signed-in app's course.
    • [App] Training (for example Schedules Training): a featured card in the app's colors with progress, watched counts, a Continue Course button and the section list. The next section to work on is highlighted; tapping a section opens the course with that section expanded.
    • Other Courses: highlighted cards for the other products, each with status, progress, video and quiz counts and a Start, Continue or Review button. Tapping the card header opens the course.
    • Completed courses are hidden from Other Courses. "Show Completed Courses (n)" shows them again.
    • Search (magnifier in the header) filters courses and matches video titles.
  3. Home – Evaluation tab
    • Section quizzes grouped the same way: the signed-in app first, then Other Courses.
    • Each card shows course and section, pass mark, best score and status: Locked, Ready, Passed or Not Passed.
    • Locked quizzes show "Watch Videos to Unlock" and open that section.
  4. Course screen
    • Progress summary, then sections as an accordion. The first unfinished section is open by default; completed sections collapse and the next opens.
    • Each section lists its videos with status, then its Section Quiz (lock icon and "Unlocks after all n videos" until unlocked).
    • Bottom button: Continue Watching, Start Course or Watch Again.
  5. Video screen
    • Dark player with Play/Pause and Fullscreen. Rewind only; progress saves automatically.
    • Fullscreen: plays in landscape with its own controls and an Exit Fullscreen button (Esc also exits).
    • "Up Next in [section]" list and the Section Quiz card below the player.
    • Auto-advance to the next video. On the last video the button becomes Take the Section Quiz once all videos are watched, otherwise Back to Course.
  6. Quiz and result
    • All questions on one scrolling page with a fixed Submit Answers button. Unanswered questions are highlighted on submit.
    • Pass: "Nice Work, You Passed!" and a button to continue to the next section. Fail: Try Again or Watch the Videos Again.
